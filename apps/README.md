# Console-native applications

This directory is the target home for independently runnable Console-native applications. `console-api/` now contains the first implemented target slice for governed operation acceptance and Registry mutation mapping. Migration from `backend/` and `src/` continues capability by capability after the corresponding machine contract and acceptance fixture exists.

The authoritative boundary inventory is `component-boundaries.json`. Sharing this repository does not permit applications to share service identities, credentials, database-writer roles, or failure state.
